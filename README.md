# tebBasket

Arcade 1v1 basketball in the browser: Canvas gameplay + React/Tailwind meta layer + Supabase.

```bash
npm install
npm run dev     # http://localhost:5173 — works offline without any backend
npm run build   # typecheck + production build
```

Full setup (Supabase schema, RLS, deploy, game-balance decisions): see [SETUP.md](SETUP.md).
